# QR decomposition 模擬專案
此專案主要上傳 QR decomposition 電路設計的 MATLAB 和 Verilog 模擬檔案。

## 專案架構

```text
QR_matlab_source_code/
QR_verilog_source_code/
QR_reference.pdf
```

## 內容說明

- `QR_matlab_source_code/`  
  放置 QR decomposition 的 MATLAB source code，主要用於演算法定點數模擬與驗證。

- `QR_verilog_source_code/`  
  放置 QR decomposition 的 Verilog source code，主要用於硬體設計與模擬。

- `QR_reference.pdf`  
  本設計所參考的文獻。
